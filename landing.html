Features

Everything you need to scale with AI

relay brings structure to AI-assisted development — so you can run multiple agents safely, without losing track of anything.

Git Worktree Isolation

Each task runs in its own dedicated git worktree. Agents never interfere with each other or your working branch — complete isolation, zero conflicts.

Conflict-free parallel work
Auto-Generated Summaries

When a task completes, relay automatically generates a concise summary of what was done — what changed, why, and what to watch for during review.

AI-powered change digest
One-Click Session Resume

Paused or completed task needs more work? Hit Restart and relay brings the Claude session back exactly where you left off — full context restored.

Persistent session state
Real-Time Status Tracking

Monitor all your agents at a glance: Running, Waiting for input, Completed, Failed, or Paused. Instant terminal output preview right on the task card.

Live dashboard updates
File Change Tracking

See exactly which files the agent touched, added, or deleted — with line-level diff counts. Full diff view before you decide to merge.

Additions & deletions per file
Built-in Git Integration

Commit, merge to your target branch, and push — all from within relay. Set the target branch when creating a task and merge in one click when done.

Commit, merge & push from UI
Task Timeline & History

Every agent prompt, response, and git snapshot is recorded. Scroll back through the full conversation history of any task at any time.

Full audit trail
Live Terminal Preview

See the last lines of agent output directly on each task card without opening it. Drill in for the full interactive terminal when needed.

Real-time output stream
Multi-Agent Support

Mix and match agents per task. Claude Code, Aider, OpenCode, or any CLI tool — each runs isolated in its own environment with its own config.

Claude · Aider · OpenCode

How it works

From task to merged code
in five steps

relay handles the heavy lifting. You stay focused on the work that matters.

01
Create a task

Describe what you want done, select your AI agent, pick a target branch, and hit Create. relay spins up an isolated git worktree and launches the agent automatically.

New Task → describe → select agent → set target branch
02
Let the agent work

The agent works in its own worktree while you continue with other things. Open other tasks, start new ones, or just close the laptop. relay tracks everything in real time.

Status: Running — watching terminal output
03
Review the results

When the task completes, review the auto-generated summary, check the file diffs, scroll through the full terminal history, and verify the changes are exactly what you wanted.

Summary · File Changes · Timeline · Terminal
04
Merge & push

Happy with the result? Commit the changes, merge them into the target branch you set at task creation, and push to remote — all without leaving relay.

Commit → Merge to main → Push
05
Restart if needed

Need tweaks? Click Restart to resume the Claude session exactly where it left off — the full conversation context is preserved. Iterate until it's perfect.

Restart → session restored → continue prompting
